# Cursor Quick Start

1. Open this entire folder in Cursor.
2. Read `HANDOFF.md`.
3. Read `AGENTS.md`.
4. Treat the current source as the V3.1 baseline.
5. Create source-control history before modifying anything.
6. Start with launch idempotency, not new UI features.
7. Preserve the existing Apps Script deployment and Sheet data model unless an explicit migration is approved.
8. Use the ready-to-paste Coder Coach prompt in Section 29 of `HANDOFF.md`.
